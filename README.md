# Autos La Frontera — Web oficial

Web oficial de **Autos La Frontera SCP**, concesionario oficial Toyota en Arucas (Gran Canaria) desde 1987.

## Archivos

- `index.html` — Web completa (archivo único con todo el contenido)
- `accesorios-*.pdf` — Fichas oficiales de accesorios Toyota por modelo (19 modelos)

## Uso

Para publicar la web, sube todos los archivos de esta carpeta al servidor o servicio de hosting. El HTML y los PDFs deben estar siempre en el mismo directorio.
